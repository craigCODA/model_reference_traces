# model_reference_traces

Experimental checkpoint traces, extraction scripts, and addressable vocabulary and continuation indexes.

## Repository contents

This initial import preserves 34 original source, test, documentation, index and trace-result files byte for byte. The original archive has 80 files; the other 46 files, including the full SQLite database, raw reference values and model assets, are not yet in this repository. See [ORIGINAL_ARCHIVE_MANIFEST.json](ORIGINAL_ARCHIVE_MANIFEST.json) for the complete original inventory and ZIP checksum. The repository is not a complete runnable copy until those assets are restored to their original paths.
